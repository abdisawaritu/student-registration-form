# Student Registration Form

A responsive student registration form built using HTML5, CSS3, Bootstrap, and JavaScript.

This project is designed to practice and demonstrate frontend web development concepts including HTML forms, responsive design, DOM manipulation, event handling, and form validation.

---

## Project Overview

The Student Registration Form allows users to enter and submit student information through a structured web form.

The project focuses on building the application from the frontend level, starting with the HTML form structure and progressively adding styling, DOM manipulation, events, validation, and JavaScript functionality.

This project is being developed as a practical project to apply the concepts learned during the frontend development learning process.

---

## Objectives

The main objectives of this project are to:

- Understand HTML form structure.
- Practice different HTML form elements.
- Build a responsive form using Bootstrap.
- Apply custom CSS styling.
- Practice JavaScript DOM manipulation.
- Practice DOM element selection.
- Handle user events.
- Read and process form values.
- Validate user input.
- Display validation errors dynamically.
- Create and manage student data using JavaScript objects.
- Practice Git and GitHub version control.
- Maintain a meaningful project development history.

---

## Features

The project will include the following features:

- Student personal information form
- Contact information
- Academic information
- Gender selection
- Date of birth
- Department selection
- Academic year selection
- Student interests
- Terms and conditions
- Form submission
- Form reset
- Client-side validation
- Dynamic error messages
- Successful registration message
- Responsive design

Additional features may be added as the project develops.
